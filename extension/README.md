# CodePoint — Chrome Extension

نسخه‌ی اکستنشن کرومِ CodePoint: همان مدیریت قطعه‌کد، اما **کاملاً مستقل از سایت** —
بدون PHP، بدون MySQL، بدون هیچ سروری. همه‌چیز روی `chrome.storage.local` ذخیره می‌شود
و کامل آفلاین کار می‌کند (حتی هایلایت سینتکس و فونت وزیرمتن داخل پکیج است).

## نصب (Load unpacked)

1. کروم را باز کن و به `chrome://extensions` برو.
2. گوشه‌ی بالا-راست، **Developer mode** را روشن کن.
3. **Load unpacked** را بزن و همین پوشه‌ی `extension` را انتخاب کن.
4. آیکون CodePoint روی نوار ابزار می‌نشیند؛ کلیک روی آن، اپ را در یک تب کروم باز می‌کند.

## امکانات

* **کلیک روی آیکون** → باز شدن اپ در یک تب کامل (بدون پاپ‌آپ)
* لیست کدها با جستجوی لحظه‌ای (عنوان / زبان / شناسه) و فیلتر زبان‌ها با شمارنده
* ثبت / ویرایش / حذف کد با همان دیالوگ و همان پیام‌های سایت
* ویوئر با هایلایت سینتکس (highlight.js 11.11.2 + ۵۳ گرامر اضافه، همه محلی)،
  شماره‌ی خط، شمارش کاراکتر/خط/حجم و «کپی با شماره خط»
* خروجی و ورود JSON با **همان فرمت بکاپ سایت** (`codepoint-backup`) — بکاپ سایت
  را می‌توانی مستقیم وارد اکستنشن کنی و برعکس
* پوسته روشن/تیره با همان منطق سایت (ذخیره در localStorage + تشخیص سیستم)
* راست‌کلیک روی متن انتخاب‌شده در هر صفحه‌ی وب → «ذخیره انتخاب در CodePoint»
  (فرم ثبت کد با آن متن از پیش پر می‌شود)
* میان‌بر `Alt+Shift+K` برای باز کردن سریع اپ
* در اولین اجرا سه قطعه‌کد نمونه (مثل نمونه‌های `database.sql`) بذر می‌شود

## ساختار

```
extension/
├── manifest.json          MV3، حداقل کروم 123 (به‌خاطر light-dark())
├── background.js          سرویس‌ورکر: باز کردن تب، منوی راست‌کلیک، میان‌بر، بذر اولیه
├── index.html / index.js  صفحه‌ی اصلی (پورت index.php به سمت کلاینت)
├── viewer.html / viewer.js ویوئر کد (پورت read.php)
├── assets/                آیکون‌ها
├── shared/
│   ├── store.js           لایه داده روی chrome.storage (جای SQLHelper + api.php + backup.php)
│   ├── ui.js              توست، کلیپ‌بورد، دیالوگ ثبت/ویرایش، پوسته، خروجی/ورود JSON
│   ├── cardmenu.js        منوی راست‌کلیک کارت‌ها
│   ├── languages.js       گروه‌ها و لیبل زبان‌ها (پورت read.php)
│   ├── theme-boot.js      پوسته قبل از اولین رندر
│   ├── fonts.css          وزیرمتن محلی
│   └── style.css          همان دیزاین‌سیستم سایت
└── vendor/                highlight.js + گرامرها + قالب‌های GitHub + فونت‌ها
```

## پرمیشن‌ها

* `storage` + `unlimitedStorage` — ذخیره‌ی کدها
* `contextMenus` — گزینه‌ی «ذخیره انتخاب در CodePoint»

هیچ دسترسی هاستی و هیچ درخواست شبکه‌ای وجود ندارد؛ اپ هیچ جایی وصل نمی‌شود.
